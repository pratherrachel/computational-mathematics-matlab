# Computational Mathematics with MATLAB

A collection of MATLAB implementations exploring numerical methods, mathematical modeling, probability, computational geometry, and optimization.

This repository brings together computational mathematics coursework, larger programming projects, and research-related implementations.

## Technical Areas

- **Numerical Methods:** Computational approaches to solving mathematical problems and analyzing numerical results.
- **Probability and Statistics:** Random sampling, probability distributions, and Monte Carlo simulations.
- **Computational Geometry:** Geometric transformations, spatial analysis, and triangulation.
- **Optimization:** Combinatorial problems, distance calculations, and route optimization.
- **Mathematical Research:** MATLAB implementations supporting advanced computational investigations.

## Running the MATLAB Scripts

1. Clone or download this repository.
2. Open MATLAB.
3. Navigate to the directory containing the desired script.
4. Ensure any required datasets are available in the appropriate directory.
5. Execute the script.

Some projects may require additional MATLAB toolboxes or project-specific configuration.
